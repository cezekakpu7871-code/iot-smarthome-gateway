# IoT Smart Home Access Control Gateway

A modular Python simulation of a smart home access gateway using object-oriented inheritance and secure device state controls.

## Key Features
- **Object Inheritance:** Demonstrates standard base-class extension (`SmartDevice` -> `SecurityDoorLock`).
- **Access Authentication:** Enforces master key code checks before state transition.
- **Timestamped System Logs:** Reports hardware activity events cleanly in console stdout.
